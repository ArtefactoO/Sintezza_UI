# Personal combat fonts

Copy the font files you want to use here as `1.ttf` through `20.ttf`. Restart WoW, then open `/sui fonts` to preview them. The optional `Tools/IndexCombatFonts.py` script from the source repository builds a local catalog with font names and Unicode coverage. Ship this directory with these instructions and keep your personal font files in your own installation.

Скопируй сюда личные шрифты под именами от `1.ttf` до `20.ttf`. Перезапусти WoW и открой `/sui fonts` для предпросмотра. Скрипт исходного репозитория `Tools/IndexCombatFonts.py` собирает локальный каталог с именами и покрытием Unicode. Личные шрифты хранятся в твоей установке.
